# Нагрузочное тестирование

## Требования (SLI)

-   **RPS**: 5 запросов в секунду
-   **Время ответа**: 95% и 99% запросов должны обрабатываться за < 300 мс
-   **Успешность**: 99.9% запросов должны быть успешными

## Запуск нагрузочного тестирования

Убедитесь, что сервис запущен (`make docker-up`), затем выполните:

```bash
make loadtest
```

Или с указанием другого URL:

```bash
LOADTEST_URL=http://localhost:8080 make loadtest
```

## Сценарий тестирования

### Этапы нагрузки

1. **Разогрев** (30 секунд): 5 RPS
2. **Основная нагрузка** (1 минута): 5 RPS
3. **Пиковая нагрузка** (2 минуты): 10 RPS
4. **Снижение** (30 секунд): 5 RPS


### Подготовка данных

Перед началом теста автоматически создаются: 5 команд, 50 пользователей (по 10 в каждой команде), 10 начальных PR.
